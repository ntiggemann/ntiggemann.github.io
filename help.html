Plane tropical curves

What it does

Given a tropical polynomial in two variables \(x\) and \(y\), draws the curve defined by it together with its dual subdivision. Further, TikZ code for both is generated.

The input

  • For the polynomials: For a term "\( a\odot x^iy^j\oplus b\odot x^ky^l\)", the input has to be "axiyj+bxkyl". So e.g. the minimal input for \[0\oplus 2\odot x^{1}y^{1}\oplus 0\odot x^{2}\oplus (-0.1)\odot x^{2}y^{1}\] is "x2+2xy-0.1x2y+0". All other symbols will be ignored.
  • Start generation of the plot by hitting enter or the "plot"-button.
  • At the bottom of the page you can find the tikz-code for the figures: Click the "TikZ for curve"-button, respectively the "TikZ for DS"-button, to get the TikZ-code for the curve, resp. its dual subdivision, displayed.
  • The settings do the following:
    • Use max-convention: Decides whether a sum gets interpreted as taking max or min.
    • Auto-adjust range: Automatically adjusts the plotting range such that all vertices can be seen in the plot.
    • Make plot a square: Forces an automatically adjusted range to be a square.
    • Min distace vertex to boundary: Forces an automatically adjusted range to keep the specified distande to the vertices.
    • Settings for manual plotting range: Here you can decide which rectangle you want to get a plot of. If not all vertices are in your range, you will get an error and a suggestion for a better range. Will be ignored if the plotting range isautomated.
    • Show coordinate lines: Draws coordinate lines.
    • Label coordinate lines: Gives the actual coordinates of the lines
    Changing tick-settings will start the plot.

Intersection of plane tropical curves

What it does

Given two tropical polynomials in two variables \(x\) and \(y\), draws their curves in blue and red together with the dual subdivision of the picture, colored accordingly. For every stable intersection point, its multiplicity gets computed. In the case of a non-transversal intersection, the overlapping parts get drawn in purple. Further, TikZ code for all of this is generated.

The input

  • For the polynomial: For a term "\( a\odot x^iy^j\oplus b\odot x^ky^l\)", the input has to be "axiyj+bxkyl". So e.g. the minimal input for \[0\oplus 2\odot x^{1}y^{1}\oplus 0\odot x^{2}\oplus (-0.1)\odot x^{2}y^{1}\] is "x2+2xy-0.1x2y+0". All other symbols will be ignored.
  • Start generation of the plot by hitting enter or the "plot"-button.
  • At the bottom of the page you can find the tikz-code for the figures: Click the "TikZ for curve"-button, respectively the "TikZ for DS"-button, to get the TikZ-code for the curves, resp. the dual subdivision, displayed.
  • The settings do the following:
    • Use max-convention: Decides whether a sum gets interpreted as taking max or min.
    • Auto-adjust range: Automatically adjusts the plotting range such that all vertices can be seen in the plot.
    • Make plot a square: Forces an automatically adjusted range to be a square.
    • Min distace vertex to boundary: Forces an automatically adjusted range to keep the specified distande to the vertices.
    • Settings for manual plotting range: Here you can decide which rectangle you want to get a plot of. If not all vertices are in your range, you will get an error and a suggestion for a better range. Will be ignored if the plotting range isautomated.
    • Show coordinate lines: Draws coordinate lines.
    • Label coordinate lines: Gives the actual coordinates of the lines
    • Shift curves: Shifts the curves by the vector specified. Note: This is done by editing the input polynomial
    • Changing settings will start the plot.

Tropical surfaces

What it does

Given a tropical polynomial in three variables \(x\), \(y\) and \(z\), draws the surface in \(\mathbb{R}^3\) defined by it together with its dual subdivision. Both plots can be rotated by dragging them with the mouse or a finger. Further, TikZ code for both is generated.

The input

  • For the polynomial: For a term "\( a\odot x^iy^jz^k\oplus b\odot x^ly^mz^n\)", the input has to be "axiyjzk+bxlymzn". So e.g. the minimal input for \[0\oplus 2\odot x^{1}z^{1}\oplus 0\odot x^{2}\oplus (-0.1)\odot y^{2}z^{1}\] is "x2+2xz-0.1y2z+0". Spaces, "*", "^" and brackets are ignored. Other symbols give an error message that shows where the input could not be read.
  • Start generation of the plot by hitting enter or the "plot"-button.
  • Drag one of the plots to rotate both of them.
  • At the bottom of the page you can find the tikz-code for the figures: Click the "TikZ for surface"-button, respectively the "TikZ for DS"-button, to get the TikZ-code for the surface, resp. its dual subdivision, displayed. The code needs the package tikz-3dplot and shows the plots from the current view.
  • The settings do the following:
    • Use max-convention: Decides whether a sum gets interpreted as taking max or min.
    • Auto-adjust range: Automatically adjusts the plotting range such that all vertices can be seen in the plot. If the surface has no vertices (because the Newton polytope is not three-dimensional), the lines or planes of minimal dimension are used instead.
    • Make plot a cube: Forces an automatically adjusted range to be a cube.
    • Min distance vertex to boundary: Forces an automatically adjusted range to keep the specified distance to the vertices.
    • Settings for manual plotting range: Here you can decide which box you want to get a plot of. Vertices outside of the box are allowed, the part of the surface inside the box is drawn. Below the plots you can see how many vertices lie outside. Will be ignored if the plotting range is automated.
    • View: The angles under which the plots are seen, as in \tdplotsetmaincoords of tikz-3dplot. They change when you drag a plot. "Reset view" goes back to the initial view.
    • Show box: Draws the back sides of the plotting range and the names of the axes.
    • Show coordinate lines: Draws coordinate lines on the back sides of the plotting range.
    • Label coordinate lines: Gives the actual coordinates of the lines.
    Changing tick-settings will start the plot.

The output

The surface is drawn in transparent blue, its edges in black. A number on a polygon is its weight, if it is bigger than 1. If the surface only touches the boundary of the plotting range in a segment or a point, this is drawn, too: black if it lies on an edge or is a vertex of the surface, blue otherwise. In the dual subdivision, the monomials of the polynomial are black, the other lattice points grey.
